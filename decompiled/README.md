# Decompiled output — Granny 2 Rework (Unreal Engine)

Generated automatically by `.github/workflows/decompile.yml`.

## What's here
- `Assets/` — every file extracted from the game's `.pak` (the whole game content)
- `Binaries/` — game executables + DLLs for local analysis (Ghidra/IDA/x64dbg)
- `AssetList.txt` — full inventory of every extracted file
- `Maps.txt` — list of level/map files (`.umap`)
- `Blueprints_Scripts.txt` — list of Blueprint assets (gameplay logic/scripts)
- `Animations.txt` — list of animation-related assets

## Notes
- This is an **Unreal Engine** build (not Unity): there is no managed C# to decompile.
- The extracted `.uasset`/`.uexp` files contain the Blueprint "script" logic as
  compiled bytecode. To read it, open them with **uAssetGUI**, **FModel**, or load
  them into the Unreal Editor. Maps are `.umap` files; meshes/textures/audio are
  also `.uasset`-based and viewable with the same tools.
- UnrealPak / repak was used for extraction: run `repak unpack` on a `.pak` to re-extract.
